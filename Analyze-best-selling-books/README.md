# 📚 Amazon Best Selling Books Analysis

## 🔹 Introduction
This project analyzes Amazon Best Selling Books using **Python** and **pandas**.  
The dataset contains 550 books with details like name, author, rating, reviews, price, year, and genre.  

## 🔹 Tools Used
- Python  
- pandas  

## 🔹 Steps Performed
1. Imported the dataset using pandas.  
2. Cleaned and explored the data.  
3. Checked ratings, reviews, and genres.  
4. Analyzed a few books to give simple **recommendations**.  

## 🔹 Conclusion
Using Python and pandas, we explored the dataset and recommended a few books based on ratings and reviews.
